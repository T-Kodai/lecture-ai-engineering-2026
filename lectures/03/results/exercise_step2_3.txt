$ uv run python -m app.agent --trace LoRAとQLoRAの違いは？
[model] gemini-3.5-flash-lite
LoRAとQLoRAの違いは以下のとおりです。

* **LoRA（Low-Rank Adaptation）**
  事前学習済みの重みを固定したまま、重みの更新分を2つの小さな行列（低ランク行列）の積で近似し、その差分だけを学習するPEFT手法です。学習するパラメータ数が非常に少なく、効率よくモデルをチューニングできます。
* **QLoRA（Quantized LoRA）**
  LoRAの仕組みをベースにしつつ、ベースモデルの重みを4ビットなどに量子化（圧縮）してメモリを大幅に節約した状態で学習する手法です。これにより、より大きなモデルを限られたGPUメモリで扱えるようになります。
